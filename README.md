# INTAIPRO

AI-powered interior design operating system built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, Zustand, and React Query.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
npm run lint
npm run build
```
